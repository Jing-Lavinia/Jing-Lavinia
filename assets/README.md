# Manual Visual Asset Slots

The text-only profile is complete without these files. Add visuals only after
reviewing them locally; never leave a broken image reference in `README.md`.

## Hero

- Filename: `profile-hero.png`
- Canvas: 1600 × 400 px
- Target size: below 500 KB
- Content: `Jing Li`, `Quantitative Researcher`, and one restrained quantitative
  motif
- Palette: navy `#071B2D`, warm ivory `#F5F0E6`, muted teal `#77C7C8`, accent
  gold `#D6B77A`
- Accessibility text: `Jing Li — quantitative research`

After upload, uncomment the image line at the top of `README.md`.

## Optional project covers

Use at most three covers, one for each flagship.

- Canvas: 1200 × 630 px
- Target size: below 350 KB each
- Filenames:
  - `equity-alpha-cover.png`
  - `crypto-relative-value-cover.png`
  - `imc-research-cover.png`

Keep typography, margins, and palette consistent. Do not display Sharpe, CAGR,
language percentages, contribution streaks, or decorative skill badges in the
cover images.

## Optional badges

Use no more than four functional badges per project: Python version, test
status, research-release status, and simulated-results scope. Avoid GitHub
stats and top-language cards.
