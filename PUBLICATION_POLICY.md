# Publication Policy

This profile is a curated recruiting interface, not the complete research
archive.

- Public project repositories contain newly assembled, publication-safe copies.
- Original repositories, private evidence, and their Git histories remain
  private and independent.
- Simulated trading evidence is separated from live-performance claims.
- Coauthored work retains full attribution and bounded contribution language.
- Third-party implementations are discussed only as attributed method studies;
  their source code is not republished.
- Raw licensed data, credentials, personal machine paths, and nonpublic
  competition or biomedical artifacts are excluded.
